# Mistfall Hunter Localization Glossary

Last reviewed: 2026-08-01. This glossary supports the first Spanish and German release. It does not claim that editorial translations are official in-game terminology.

## Official names retained in English

The following names stay in English in Spanish and German copy until a stable official localization can be verified: `Mistfall Hunter`, `Gyldhunter`, `Gyldenmist`, `Gyldenblood`, `Returner Woodling`, `Soul of Return`, `Affix Gems`, `Loadout`, `Mercenary`, `Sorcerer`, `Blackarrow`, `Shadowstrix`, `Seer`, `Withered Knight`, `Sword & Shield`, `Hammer`, `Greatsword`, and `Polearm & Shield`.

## Spanish editorial terms

| English concept | Spanish term used | Note |
| --- | --- | --- |
| beginner guide | guía para principiantes | Neutral Latin American Spanish |
| extraction / extract | extracción / extraer | The item and creature names remain English |
| build | build | Common search term; configuration is used for explanation |
| solo play | juego en solitario / jugar solo | Does not mean PvE-only |
| class tier list | tier list de clases | Explicitly editorial, never official |
| servers | servidores | Countries are reproduced only from the official FAQ |
| region lock | bloqueo regional | Account-region rule, not a latency label |
| redeem code | código de canje | Kept separate from share codes, game keys and Drops |
| stuttering | tirones / microtirones | Used only in explanatory copy, not current Spanish routes |
| crash | cierre inesperado / bloqueo | Platform behavior must be stated |

## German technical terms

| English concept | German term used | Note |
| --- | --- | --- |
| settings | Einstellungen | Grafik- and performance context |
| stuttering | Ruckler / Mikroruckler | Frame-Time-Muster is used for diagnosis |
| crash | Absturz | Freeze and Dashboard-Rückkehr remain distinct symptoms |
| frame time | Frame Time / Frame-Time-Muster | Common German PC terminology |
| frame cap | Frame-Limit | No guaranteed improvement claim |
| shader precompilation | Shader-Vorkompilierung | Used only where official DevNote context supports it |
| asset loading | Asset-Loading | Official technical context |
| server status | Serverstatus | No live telemetry is claimed |
| account region | Kontoregion | Distinguished from residence and connection route |
| region lock | Region Lock | Search term retained; explained as Regionsbeschränkung |

## Editorial rules

- Do not translate an unverified official UI label just to make copy sound complete.
- Do not convert Beta or Demo terminology into a launch fact.
- Preserve source level, check date, platform and version on high-risk pages.
- Translate the explanation around official names, then show the English name readers need to recognize in the client.
- Community observations must stay labeled and cannot establish a universal rate, best build or guaranteed fix.
